# 醫務櫃檯・護理人員排班系統

離線單機版（瀏覽器開啟 `index.html` 或雙擊 `開啟排班系統.cmd`），資料存在本機瀏覽器 localStorage。

## 預設條件

| 班別 | 時間 | 時數 | 適用 |
|---|---|---|---|
| A | 08:00–12:00 | 4 | 週一～五 |
| B | 13:30–17:30 | 4 | 週一～五 |
| C | 17:50–21:30 | 3h40m（約 3.67） | 週一～五 |
| D | 08:00–12:00 | 4 | 週六 |
| E | 13:30–17:30 | 4 | 週六 |

- 週日為例假（休診）。班別代碼、名稱、時間、適用星期皆可在「智慧排班與設定」新增、修改、刪除。
- 組合：AB（8h）、BC（約 7.67h）優先；人力不足時才排 AC；週六 DE／單 D／單 E。工時顯示到小數兩位。
- 標準班別（`settings.standardGroups`，預設醫務櫃檯、護理、藥師；設定頁「班別時段」下方可勾選）：只排相鄰兩節 AB 08:00–17:30、BC 13:30–21:30、週六 DE 08:00–17:30，不排 AC 兩頭班；前一天晚班使隔天只剩單節時，該節人力不足或本人希望才上，否則改休。本人請半天假（如「午休」）仍照上另一節。代價是 B 節人力較多、A／C 節缺口略增（原本 AC 一人可補兩頭），由兼職補。醫檢師未勾選，維持原規則。
- 每個班別可另訂「醫務櫃檯時間」（預設不另訂，全員同時間）；兼職依當節支援的崗位（櫃檯或護理崗位）計時。舊版資料的預設 C 班（護理 18:00／櫃檯 17:30）開啟時自動改為 17:50–21:30，自訂過的時間不動。
- 工時保障（預設開啟）：週五晚班者隔日只能上 E（單節 4h），C 不足 4h 時會使工時跌破 152h，因此系統讓當週晚班同仁週六排休，所有正職維持 152–160h；代價是週六護理人力較少、護理晚班次數差距較大（約 8 次）。可在設定關閉。
- 人員：醫務櫃檯 F1–F5（每節 4 櫃）、護理 N1–N9（每節胃鏡室 1–2、檢驗室 2–3、跟診 3–4）、兼職 P1–P4（每週 3～4 節，可調 0～8 人）。姓名、崗位、兼職可支援時段皆可修改。
- 藥師（PH，崗位「調劑」）與醫檢師（MT，崗位「醫檢」）是自動排班組別，和醫務櫃檯、護理一樣由一鍵排班排例休、班別與崗位，做勞基法檢核與公平度（`E.FT_GROUPS`）。預設需求只有康華藥局調劑 1 人、睿康檢驗所醫檢 1–2 人，其餘院所 0；沒有需求也沒人排的崗位不在當日崗位、覆蓋列與崗位明細顯示。兼職可勾選支援調劑／醫檢（預設不勾）。Excel 列標題含「調劑／配藥」「醫檢」會對應到這兩個崗位；重新匯入 Excel 只重建醫務櫃檯、護理與固定兼職，藥師、醫檢師保留。
- 法規：四週正常工時 ≤ 160h（目標 152h）、四週例假 4 天＋休息日 4 天、每兩週至少 2 例、單日 ≤ 10h、輪班間隔 ≥ 11h（C 班隔日不排 A/D）、連續上班 ≤ 6 天。

## 五大面板

1. **排班大表**：第 1～4 週／四周全覽、組別篩選；點格子可改 AB/BC/AC/A/B/C/D/E/例/休 與崗位、櫃位，即時顯示法規警示與當節人力。
2. **當日崗位**：日期＋28 天快捷鈕，各節崗位名單（櫃檯櫃位 1–4），一鍵複製 LINE 通報。
3. **個人班表**：工時、上班日、例、休、AB/BC : AC、晚班次數、四週日曆、崗位輪調卡、全員統計表。
4. **法規平衡**：§30-1 檢核清單、工時圖、晚班分布、護理崗位輪調圖、公平度分數、人力產能與缺口分析。
5. **需求標準**：每日、每節需求人力標準設定表（見下節）。
6. **希望休假**、7. **希望班別**：同仁預排自己的休假與想上的班。
8. **預排建議**：綜合上面三頁產生建議班表，確認後採用。
9. **智慧排班與設定**：一鍵排班（本期／連排 3、6 期）、每節需求滑桿與逐班微調、兼職人數滑桿、班別與名單維護、法規參數、CSV／崗位明細／剪貼簿匯出、JSON 備份還原。

## 需求標準、希望休假、希望班別、預排建議

- **需求標準**（`state.weekDemand[院所][星期][班別][崗位] = {min, max}`）：星期 × 班別 × 崗位的最少／最多人數，黃底為該星期另設，其餘沿用設定頁的班別預設。可「套用到平日」「還原」。需求優先序：Excel 逐日需求 → 星期標準 → 班別預設 → 崗位預設；本期有 Excel 逐日需求時可按「本期改用標準表」。
- **希望休假**（`state.requests`）：全日休或早／午／晚不排，可勾「套用到本期每週同一天」。硬性條件，一定遵守；全日休算入休息日，每人超過四週休息日天數時標紅。底列為當天全日休人數，可上班人數低於單節最低需求時標紅。
- **希望班別**（`state.wishes[日期][人員] = { shifts: ['A','B'] }`）：早午、午晚、早晚或單節。軟性條件：每週休息日避開希望上班的日子；當天在不超過每節最多人數、且補到的缺額不少於系統原選擇時採用（需求優先，人力不足時「只上單節」的希望會改排含該節的兩節）；兼職優先排入希望的節。填了休假的那天以休假為準。
- **預排建議**：按「產生預排建議」以上述三頁＋法規產生各院所建議班表（不覆蓋目前班表），顯示與目前班表的違規、缺口、覆蓋率、休假達成率、班別符合率比較，每位同仁的達成情形與未達成日期，以及標示符合／部分／未符合的預覽表；按「採用為本期班表」才寫入。一鍵排班也使用同一套規則。
- 重新匯入 Excel 只清除上次 Excel 帶入的預假（`src: 'excel'`），同仁自填的休假保留。
- Excel 固定班人員只有在該期有指定班時才整期沿用 Excel，其他期別照常由系統排班（`E.isFixedIn`）。

## 人力產能說明

以預設需求計算，每四週最低需求約為：櫃檯 272 人次節、護理 408 人次節；正職可供給櫃檯 200、護理 360（每人 20 天 × 2 節），兼職 4 人約可補 56。
**最低需求超出可合法排班的人力約 64 人次節**，系統會如實標示缺口（不會以違法加班補足），可在設定頁調降需求、增加兼職或其可支援時段。

若醫務櫃檯 C 要和護理不同時間，在班別表的「醫務櫃檯時間」欄修改即可，工時會自動重算。

## 各院所分別排班

院所：內壢敦仁、青埔敦仁、新陳代謝、康華藥局、睿康檢驗所、康華健康（後三者預設需求：康華藥局調劑 1 人、睿康檢驗所醫檢 1–2 人、康華健康櫃檯 1 人，其餘崗位 0，可在「需求標準」或設定頁調整）。「智慧排班與設定 → 同仁名單」每人可選院所；頂部院所切換鈕決定排班大表、當日崗位、個人班表、法規平衡與「每節人力需求」顯示哪一院。

- 每院各有一套每節人力需求（`state.demand[院所][班別][崗位]`）與逐日需求（`state.dateDemand[院所][日期]`）
- 一鍵排班時逐院排班（`E.siteView` 只含該院同仁與需求），同仁只會排在自己的院所；沒有同仁的院所略過
- 法規、覆蓋、產能、公平度皆逐院計算（`A.analyzeSites`）；班表 CSV、崗位明細與 LINE 通報含院所
- 舊版資料（單一院所）自動歸到內壢敦仁；Excel 中「敦仁青埔」列歸青埔敦仁，其餘歸內壢敦仁

## 醫師、營養師、衛教師（手動填班）

同仁名單另有三類手動組別：醫師（DR）、營養師（RD）、衛教師（HE），可設定姓名、院所、職務、在職。（藥師已改為自動排班，見上方預設條件。）

- 只列名單：班別在排班大表點格子手動填（不選崗位），系統照算工時並做勞基法檢核；本期未填任何班者不檢核。醫師只計工時與節數，不做勞基法檢核（`E.isLaborExempt`）
- 一鍵排班不會排也不會覆蓋他們的班（`E.generate(state, start, 原班表)` 保留手動組別）
- 不計入櫃檯／護理崗位覆蓋；當日崗位與 LINE 通報各節另列「醫師：…」等
- 匯入 Excel 時，「班別」列到「總合」之間的診間列視為醫師門診：建立／更新醫師名單（院所、科別取看診節數最多者），Excel 涵蓋的日子寫入門診班，無門診標休、週日標例；「-請假」不算門診，「-八德」等外診照算並列為備註。其他手動組別的班不受影響
- Excel 院址對應：敦仁診所 → 內壢敦仁、敦仁青埔 → 青埔敦仁、敦仁12號（新代）→ 新陳代謝
- 醫師依「醫師門診時間」計工時（預設早 08:30–12:00、午 14:00–17:30、晚 18:00–21:30，可在班別表修改）
- 排班大表可用「醫師・醫事」篩選

## 匯入 Excel 預估人班表

頂部「📥 匯入 Excel」或設定頁的匯入卡片，可讀取「預估人班表」格式（每週一區塊：星期／日期／行事曆／班別／診間／崗位）：

- 「醫務」「護理」格 → 該日該節的崗位需求（逐日，取代班別預設需求）
- 寫人名 → 指定班（🔒）；每週 ≥ 8 節者視為固定班正職（如青埔），1–8 節者為固定兼職，其餘由系統排
- 「支援」→ 需兼職或外援補足；他院人員（如 18 號、項思嘉）只統計、不列入本系統
- 行事曆「某某休／午休／晚休」→ 預假；「某某10/26」→ 國定假日補休
- 早／午／晚 對應 A／B／C，週六早／午 對應 D／E；連續四週自動成為一期，可一次匯入多期
- 匯入時帶入院所（依名字出現最多的院區）與職務（醫務櫃檯／護理師／兼職醫務／兼職護理），設定頁人員表可修改並顯示本期工時

### 內建資料（免手動匯入）

`data/presets.js` 定義 `window.ROSTER_PRESETS[代號] = { label, file, state }`，以 `index.html?preset=代號` 開啟即自動載入（加 `&week=0~4` 指定顯示週）；設定頁匯入卡片也有「載入內建」按鈕。此檔含人員個資，已列入 `.gitignore`，只放在部署資料夾。
