# 醫務櫃檯・護理人員排班系統

離線單機版（瀏覽器開啟 `index.html` 或雙擊 `開啟排班系統.cmd`），資料存在本機瀏覽器 localStorage。

## 預設條件

| 班別 | 時間 | 時數 | 適用 |
|---|---|---|---|
| A | 08:00–12:00 | 4 | 週一～五 |
| B | 13:30–17:30 | 4 | 週一～五 |
| C | 護理 18:00–21:30／櫃檯 17:30–21:30 | 護理 3.5／櫃檯 4 | 週一～五 |
| D | 08:00–12:00 | 4 | 週六 |
| E | 13:30–17:30 | 4 | 週六 |

- 週日為例假（休診）。班別代碼、名稱、時間、適用星期皆可在「智慧排班與設定」新增、修改、刪除。
- 組合：AB（8h）、BC（護理 7.5h／櫃檯 8h）優先；人力不足時才排 AC；週六 DE／單 D／單 E。
- 每個班別可另訂「醫務櫃檯時間」；兼職依當節支援的崗位（櫃檯或護理崗位）計時。
- 工時保障（預設開啟）：週五晚班者隔日只能上 E（單節 4h），護理 C 僅 3.5h 時會使工時跌破 152h，因此系統讓當週晚班同仁週六排休，所有正職維持 152–160h；代價是週六護理人力較少、護理晚班次數差距較大（約 8 次）。可在設定關閉。
- 人員：醫務櫃檯 F1–F5（每節 4 櫃）、護理 N1–N9（每節胃鏡室 1–2、檢驗室 2–3、跟診 3–4）、兼職 P1–P4（每週 3～4 節，可調 0～8 人）。姓名、崗位、兼職可支援時段皆可修改。
- 法規：四週正常工時 ≤ 160h（目標 152h）、四週例假 4 天＋休息日 4 天、每兩週至少 2 例、單日 ≤ 10h、輪班間隔 ≥ 11h（C 班隔日不排 A/D）、連續上班 ≤ 6 天。

## 五大面板

1. **排班大表**：第 1～4 週／四周全覽、組別篩選；點格子可改 AB/BC/AC/A/B/C/D/E/例/休 與崗位、櫃位，即時顯示法規警示與當節人力。
2. **當日崗位**：日期＋28 天快捷鈕，各節崗位名單（櫃檯櫃位 1–4），一鍵複製 LINE 通報。
3. **個人班表**：工時、上班日、例、休、AB/BC : AC、晚班次數、四週日曆、崗位輪調卡、全員統計表。
4. **法規平衡**：§30-1 檢核清單、工時圖、晚班分布、護理崗位輪調圖、公平度分數、人力產能與缺口分析。
5. **智慧排班與設定**：一鍵排班（本期／連排 3、6 期）、每節需求滑桿與逐班微調、兼職人數滑桿、班別與名單維護、法規參數、CSV／崗位明細／剪貼簿匯出、JSON 備份還原。

## 人力產能說明

以預設需求計算，每四週最低需求約為：櫃檯 272 人次節、護理 408 人次節；正職可供給櫃檯 200、護理 360（每人 20 天 × 2 節），兼職 4 人約可補 56。
**最低需求超出可合法排班的人力約 64 人次節**，系統會如實標示缺口（不會以違法加班補足），可在設定頁調降需求、增加兼職或其可支援時段。

若護理 C 也要改為 17:30–21:30，在班別表把「護理／兼職時間」的 C 開始時間改為 17:30 即可，工時會自動重算。

## 匯入 Excel 預估人班表

頂部「📥 匯入 Excel」或設定頁的匯入卡片，可讀取「預估人班表」格式（每週一區塊：星期／日期／行事曆／班別／診間／崗位）：

- 「醫務」「護理」格 → 該日該節的崗位需求（逐日，取代班別預設需求）
- 寫人名 → 指定班（🔒）；每週 ≥ 8 節者視為固定班正職（如青埔），1–8 節者為固定兼職，其餘由系統排
- 「支援」→ 需兼職或外援補足；他院人員（如 18 號、項思嘉）只統計、不列入本系統
- 行事曆「某某休／午休／晚休」→ 預假；「某某10/26」→ 國定假日補休
- 早／午／晚 對應 A／B／C，週六早／午 對應 D／E；連續四週自動成為一期，可一次匯入多期
- 匯入時依出現院區帶入職務（如「醫務櫃檯（青埔）」「兼職護理」），設定頁人員表可修改職務並顯示本期工時

### 內建資料（免手動匯入）

`data/presets.js` 定義 `window.ROSTER_PRESETS[代號] = { label, file, state }`，以 `index.html?preset=代號` 開啟即自動載入（加 `&week=0~4` 指定顯示週）；設定頁匯入卡片也有「載入內建」按鈕。此檔含人員個資，已列入 `.gitignore`，只放在部署資料夾。
