# 醫療人員綜合排班系統

整合護理師、醫務人員、營養師、藥師、衛教師的門診／診所班表，採**勞基法四週變形工時（§30-1）**。

## 快速開始

雙擊 `開啟排班系統.bat`，或用瀏覽器開啟 `index.html`。

### 期別（四周變形工時）

排班單位為 **28 日一期**，顯示格式：

`YYYY/MM/DD~YYYY/MM/DD`

主管可於上方列設定：

1. 選擇批次起日（自動對齊週一）  
2. 選擇一次排定 **3～6** 期  
3. 按「產生期別批次」  
4. 以芯片切換「目前檢視期別」  
5. 在「期別排班」可「自動排本期」或「自動排整批」

### 示範登入

| 身分 | 帳號 | 密碼 | 權限 |
|------|------|------|------|
| 系統管理員 | `admin` | `admin` | 全部職務、匯入／重置 |
| 護理主管 | `nurse` | `demo` | 僅護理師 |
| 醫務主管 | `medical` | `demo` | 僅醫務人員 |
| 營養主管 | `dietitian` | `demo` | 僅營養師 |
| 藥師主管 | `pharmacist` | `demo` | 僅藥師 |
| 衛教主管 | `educator` | `demo` | 僅衛教師 |
| 同仁（例） | `n1` | `demo` | 自排班＋看自己班表 |

同仁帳號＝人員 ID（人員名單頁可見），密碼預設 `demo`。

## 權限摘要

- **管理員**：全院名單／配班／自動排班／合規／JSON 備份
- **職務主管**：只能管自己職務；自動排班不覆寫其他職務；可匯出該職務 Excel
- **同仁**：只填自己的希望班；月班表唯讀；可匯出個人 Excel

## 匯出 Excel

工具列「匯出 Excel」或月排班頁按鈕。產生 `.xls`（SpreadsheetML，Excel／WPS 可開），含：

1. 匯出說明  
2. 日曆班表（每日早／午／晚）  
3. 人員班表（姓名 × 日期＋節數統計）

無需安裝套件，可離線使用。

## 班別

| 日 | 早班 | 午班 | 晚班 |
|----|------|------|------|
| 週一～五 | 08:00–12:00 | 13:30–17:30 | 17:30–21:30 |
| 週六（假日班） | 08:00–12:00 | 13:30–17:30 | — |
| 週日 | 原則例假／休息，不排班 | | |

每節 **4 小時**。單日最多排 3 節（12h；其中正常工時上限 10h，超出計延長）。

## 使用流程

1. **人員名單**：各職務主管維護基本名冊與分組  
2. **配班設定**：每人每週早／午／晚／假日目標節數＋各職務每班覆蓋人數  
3. **自排班**：同仁填希望／可／不要，並勾不可上班日  
4. **月排班**：按「依希望自動排班」，再手動微調  
5. **四周合規**：檢查 160h、例假、休息日等

## 四週變形工時檢核

- 每日正常工時 ≤ 10 小時  
- 四週正常工時 ≤ 160 小時  
- 每二週例假 ≥ 2 日  
- 每四週例假＋休息日 ≥ 8 日  
- 當日正常達 10h 時，延長 ≤ 2h（當日總工時 ≤ 12h）

需屬中央指定行業，並經工會或勞資會議同意後始得實施。
